    // FAQ
    
    
    The questions judges ask, answered straight.
    
    
    
      
    Run the scorer yourself
    
      
    python scripts/local_score.py --url 
    
    
    
  
    
  
    
    
    Does it ever invent a step?
    No. Steps are copied from the SIIS text and only split at sentence boundaries. The simulator's “Grounded” figure checks every step against the article on each run.
    
    
    What happens when no deeplink fits?
    If the steps open a Settings screen that the catalogue doesn't have, the group gets bixby://dummy_positive with a 5–7-word description naming that screen. If nothing points at Settings, the group gets no link and the action stays manual.
    
    
    How can a paraphrase be a cache hit and still be right?
    Parsing, grouping and deeplink resolution depend only on the article. A reworded query reuses that plan, and the goal name, kind and score are recomputed for the new wording. The tests check that a paraphrase hit is byte-identical to a fresh run.
    
    
    What makes an action critical?
    Anything destructive or safety-related: factory reset, clearing data, erasing, liquid or physical damage, a swollen or overheating battery. The simulator asks for confirmation before walking through them.
    
    
    What does Gemini do, and what can't it do?
    Gemini refines plans on cache misses: it names unfamiliar topics, writes "It will…" descriptions, paraphrases queries, and breaks ties between shortlisted catalogue entries. It never writes steps or deeplink URIs. Every answer is validated and time-limited, and on any failure the rules' answer is used. Results are cached in data/llm_cache.json, so repeats and the committed kit plans need no call.
    
    
    Where does it run?
    One container serves both this site and the API: docker build -t sgte . && docker run -p 8000:8000 sgte. To point the site at another deployment, add ?api=https://host to the URL.
